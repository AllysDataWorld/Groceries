How shopping is calculated

There are two users settings: threshold and min_purchase

Items are suggested when today's date is past or close to the predicted purchase date.

Average Interval is the average number of days between purchases.

Calcluation:

Number of days since the last time this [item/category] was purchased divided by the Average Interval for this [item/category]

If this number is past a certain threshold, it will be included in the shopping list.

Threshold is a number between 0-1. By Default its set to .8

This 0.8 means that when 80% of typical interval has passed then include the item in the shopping list


min_purchases: Minimum number of purchases needed to include item in predictions. Default 3 ensures we have reliable data
